# Lime 评测

评测比较真实上文和当前词拼音下的第一候选是否严格等于原文词。模型只负责重排 Rime 已召回的候选，不生成或改写文本；“仅 Rime”行始终使用 Rime 首候选。

## 语料目录

语料由用户提供，不在安装包内。服务默认读取 `%LOCALAPPDATA%\Lime\benchmark\corpora`，开发/测试可用 `LIME_BENCHMARK_CORPUS_DIR` 覆盖。目录的每个直接子文件夹是一类语料，文件夹中的每个 UTF-8 `.txt` 文件是一篇文章。只有这些文件参与评测，顺序按文件夹名和文件名稳定排序。

管理页“刷新语料”会重新读取全部文件，使用 Rust `jieba-rs` 分词，并优先用随 Rime-Ice 提供的 `cn_dicts` 词级读音处理多音词；找不到词条时自动回退到 `pinyin` 的单字默认读音，不要求用户手动注音。无法读取、不是 UTF-8、无法分词或不含中文目标的文件会使刷新失败，并显示具体路径。语料元数据只包含类别、文章数、汉字数、目标词数和指纹，不向管理窗口传输文章全文。

指纹包含评测算法/处理器版本、类别和文章相对路径、文件原始字节，不包含词典内容。文章内容、路径、类别或处理器版本变化后，旧结果保留在磁盘上但不会复用。开发样例位于 `crates/lime-benchmark/data/corpora/`，已由 Git 忽略。

每篇文章的第一个中文词也计入分母。它的前文为空，始终取 Rime 首候选，不调用 LLM；即使文件开头是标点、字母或数字，也按该文章第一个中文词处理。后续目标的前文保留原始非中文字符，并截取目标前最多 `preceding_text_char_limit` 个 Unicode 字符。

## 选择和执行

评测页可以选择多个已保存模型、`仅 Rime`、全拼/首拼模式、语料类别和多行配置。模型行按模型 × 配置 × 拼音模式去重，最多 32 行；仅 Rime 忽略配置，每种拼音模式只生成一行。语料是每行的列，不计入 32 行限制。

开始后服务先对选中的语料和拼音模式建立共享 Rime 候选快照，再串行执行组合。Rime 方案、词库或候选顺序在快照期间发生变化会使批次失败。页面只把当前模型/当前语料显示为进度条，其余组合列在等待队列中；当前项显示已处理词数、实时词速和预计剩余时间。

## 结果和复用

结果保存在服务数据目录的 `benchmark/index.json` 和 `benchmark/items/<key>.json`。缓存 key 只包含模型文件指纹、有效配置、拼音模式、语料类别、语料指纹和评测算法版本；Rime 候选快照指纹仍记录在结果中用于追踪，但候选顺序变化不会让已有结果失效。只有完整成功的评测才会写入可复用记录，写入使用临时文件后原子替换。打开评测或开始新批次时会自动复用当前 key 下的完成项。

表格一行显示模型、配置和拼音模式；每个语料单元格显示准确率和错误数，点击单元格打开详情。错误记录完整保存在对应组合文件中，通过分页 IPC 读取，详情显示准确率、分母、错误数、上文、拼音、目标词和首位结果，并可以“重新测此项”。“清空结果”删除全部持久化评测记录，但不删除语料目录；重新测单项只删除并重跑该单元格。

停止会在当前词处理完后生效，当前项和等待项会显示停止状态；未完成项不会写入可复用记录。评测不写输入历史、不上传文本。
