# Lime 评测语料

评测语料由用户在运行时提供，**不会随安装包发布，也不进入 Git**。服务默认读取：

```text
%LOCALAPPDATA%\Lime\benchmark\corpora
```

开发和测试可以设置 `LIME_BENCHMARK_CORPUS_DIR` 覆盖该路径。目录的直接子文件夹就是语料类别，文件夹中的每个 UTF-8 `.txt` 文件是一篇文章；文件夹名同时是类别 ID 和显示名。文件夹、文件均按稳定的字典序读取，其他层级和扩展名会被忽略。

本开发目录中的忽略样例为：

| 类别 | 文章数 | 当前汉字数 | 当前目标词数 |
| --- | ---: | ---: | ---: |
| 知乎 | 30 | 61,921 | 35,797 |
| 经典文章 | 20 | 53,086 | 34,241 |

全部语料文本统一为简体中文。经典文章只保留现代白话作品，共 10 位作者，不含古文。经典文章文件名统一为“中文标题 作者”，正文已去掉出版日期、原载说明、版本说明、舞台提示等非正文文字。按正文汉字数计算，作者占比最高的是老舍 17.84%、鲁迅 17.70%、许地山 16.13%、朱自清 15.83%，其余作者均低于 14%，没有作者超过 20%。这些数字会随文件内容变化，界面以运行时刷新结果为准。`data/sources/` 保存维护用的来源快照；`data/corpora/` 保存当前开发样例。二者都由 `.gitignore` 排除，不能作为安装包资源。

## 运行时处理

服务使用 Rust 的 `jieba-rs` 精确模式加载目录并校验 UTF-8、分词；拼音优先从随 Rime-Ice 提供的 `cn_dicts` 词级词典获取，找不到词条时自动回退到 `pinyin` 的单字默认读音，因此不需要用户手动注音。混合词会按连续中文片段拆开；字母、数字、标点和空白保留在后续上文中，但不会成为目标。每篇文章的第一个中文词也进入分母，使用空前文和 Rime 首候选，不调用 LLM。

刷新时会校验每篇文章都能完整分词、每个目标都有自动生成的拼音且不超过评测限制。词典不可用或缺少词条时仍使用单字默认读音；只有文件错误才会使本次刷新失败，并返回具体路径。语料指纹包含处理算法版本、类别和文章相对路径、文件原始字节，不包含词典内容；内容、路径或处理器版本变化都会使旧的评测组合失效。

服务不会读取或生成旧版编译进程序的 `corpus.json`。修改样例后，运行管理窗口的“刷新语料”，或设置环境变量后重新启动服务。

## 开发命令

```powershell
$env:LIME_BENCHMARK_CORPUS_DIR = (Resolve-Path crates/lime-benchmark/data/corpora).Path
cargo test -p lime-benchmark
```

来源文本的维护脚本仍在 `tools/prepare-benchmark-corpus.py`；它只用于整理忽略的开发快照，不是运行时依赖。
